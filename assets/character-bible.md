# 角色設定 bible

所有角色皆為高中生；水彩、色鉛筆、深藍墨線、校園制服、自然身形比例。角色僅為 Avatar，不代表人格或答案。

| 角色 | 視覺辨識 | 配色 |
|---|---|---|
| 阿樂 | 微捲短髮、帆布鞋 | 靛藍 |
| 小晴 | 及肩直髮、圓框眼鏡 | 珊瑚橘 |
| 阿凱 | 側分短髮、腕錶 | 墨綠 |
| 小米 | 高馬尾、斜背小包 | 琥珀黃 |
| 阿哲 | 蓬鬆短髮、球鞋 | 海軍藍 |
| 小安 | 短鮑伯、髮夾 | 紫羅蘭 |
| 阿昕 | 微長髮、耳機掛頸 | 青綠 |
| 小宇 | 平瀏海、背包徽章 | 磚紅 |

使用方式：既有 `characters.png` 為角色選擇圖；結局採角色名＋職業徽章＋背景的分層呈現，避免將座號呈現於畫面。
